# Power BI & Power Platform

> Modelo de importação construído a partir do HTML original. As três trilhas abaixo são seções de um único curso na página de seleção. Os módulos possuem XP total, distribuído proporcionalmente entre suas unidades, como no HTML.

## Instruções do formato

- `## Trilha:` inicia uma seção interna; `### Módulo:` inicia um módulo; `#### Unidade:` inicia uma unidade.
- Mantenha os identificadores `id` estáveis e únicos; são usados para preservar o progresso em futuras atualizações.
- Campos apresentados como `- chave: valor` devem ser interpretados pelo importador, não como aulas adicionais.
- `xp` no módulo é o total do módulo: cada unidade vale `xp / quantidade_de_unidades` e o XP global é arredondado somente ao final, conforme o HTML original.
- Uma unidade só pode ser marcada ou desmarcada após confirmação; conquistas e XP são recalculados a cada alteração.
- URLs são referências externas; use apenas protocolos seguros e valide o Markdown antes de importar.
- O administrador define quem tem acesso a este curso. Todas as seções internas são parte do mesmo curso.

## Regras de implementação

- `completedUnits` armazena somente os IDs das unidades concluídas por usuário e por curso.
- Um módulo é concluído apenas quando todas as suas unidades estão concluídas.
- A quantidade de unidades e o XP não podem ser duplicados por cliques repetidos.
- Ao desmarcar uma unidade, o XP diminui e conquistas deixam de estar desbloqueadas caso os requisitos não sejam mais atingidos.
- A lista de conquistas desbloqueadas deve ser derivada do progresso atual, em vez de ser usada como fonte de verdade.
- Preserve as cinco conquistas originais, inclusive a condição original da conquista Explorador Power BI, que conta cinco módulos completos no total; se desejar restringir essa condição aos módulos de Power BI, altere explicitamente a regra.
